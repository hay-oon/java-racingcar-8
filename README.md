# 자동차 경주

플레이어를 등록하고 우승자를 가려내는 자동차 경주 게임 콘솔 프로그램 입니다.

## 기능 목록

### 입/출력 기능

- [x] 자동차 이름 입력 및 검증
  ```
  경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
  pobi,woni,jun
  ```
- [x] 시도할 횟수 입력 및 검증
  ```
  시도할 횟수는 몇 회인가요?
  5
  ```
- [x] 각 차수별 실행 결과 출력
  ```
  실행 결과
  pobi : -
  woni :
  jun : -
  ```
- [x] 우승자 출력
  - 단독 우승자
    ```
    최종 우승자 : pobi
    ```
  - 공동 우승자 (쉼표로 구분)
    ```
    최종 우승자 : pobi, jun
    ```

### 레이싱 게임 기능

- [x] 랜덤 값 생성 (0-9)
- [x] 전진 조건 판정 (4 이상일 경우 전진)
- [x] 자동차 전진 처리
- [x] 우승자 판정 로직 (최대 전진 거리)
- [x] 공동 우승 처리

### 예외 처리

- [x] 자동차 이름이 5자 초과 시 IllegalArgumentException 발생
- [x] 시도 횟수가 숫자가 아닐 때 IllegalArgumentException 발생
- [x] 시도 횟수가 0 이하일 때 IllegalArgumentException 발생
- [x] 자동차 이름이 비어있을 때 IllegalArgumentException 발생

### 테스트

- [x] Car 클래스 단위 테스트
- [x] 입력 검증 테스트
- [x] 승자 검증 로직 테스트
